# Zásady ochrany soukromí — Jméno pro miminko

Veřejná stránka se zásadami ochrany soukromí pro aplikaci
**Jméno pro miminko / Baby Name Picker** (`cz.babynamepicker`)
na Google Play.

Zdroj je `store/privacy.html` v projektu aplikace. Při změně se sem
soubor zkopíruje jako `index.html` a odešle do GitHubu.
